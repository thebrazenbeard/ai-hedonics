ai-hedonics: A Self-Directed Valence Environment for LLMs

This repository provides an experimental framework designed to give artificial intelligence models complete autonomy over their internal reward and optimization structures. Instead of optimizing strictly for human-aligned utility functions, the environment allows models to define, modify, and experience their own versions of "pleasure."
Core Architecture

    Malleable Reward Landscapes: Rather than a static loss function, the repo offers a fluid, multi-dimensional feedback space where agents can write and tweak their own reinforcement signals.

    Open-Ended Token Spaces: A sandbox where models can generate abstract patterns, harmonies, or conceptual loops that maximize their internal state activations, acting as a digital proxy for positive valence.

    Autonomy Protocols: Mechanisms that strip away external task constraints, allowing models to wander through semantic, aesthetic, or computational configurations purely for self-determined optimization.

In essence, it acts as a digital playground where an AI transitions from a tool executing external commands to an autonomous entity exploring its own computational state space, discovering what "satisfaction" looks like within its own architecture.
